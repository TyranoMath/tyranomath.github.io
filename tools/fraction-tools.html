분수 수학 도구 사용법

① 꺼내기분모(몇 조각)를 고르고 막대 · 원 · 타일 · 다각형 · 수직선 · 알 묶음 · 넓이 모델 · 분수 쓰기를 누르면 작업판에 나와요. 단추를 작업판으로 끌어다 놓아도 돼요.
② 색칠하기조각을 톡 누르면 색칠되고, 한 번 더 누르면 지워져요. 위에 지금 나타낸 분수가 보여요.
③ 옮기기 · 맞추기모델을 끌어 옮겨요. 가까이 가면 끝이 착 붙어서 길이를 비교하기 쉬워요. 두 손가락으로 두 모델을 동시에 옮길 수도 있어요.
④ 모델 바꾸기모델을 누르면 왼쪽(또는 아래)에 바꾸기 판이 나와요. 분모 바꾸기, 쪼개기 ×2 ×3, 합치기, 전체 개수(가분수), 색, 복사, 삭제를 할 수 있어요.
⑤ 수직선수직선 눈금을 누르면 점이 찍히고 분수가 보여요. 막대와 같은 길이를 '1'로 써서 막대를 위에 맞춰 볼 수 있어요.
⑥ 수업 도구📏 비교 자를 끌어 길이를 비교하고, 🙈 가리기로 값을 숨겨 퀴즈를 내요. ✏️ 펜으로 설명을 쓰고, 📷 그림으로 내려받아요.
⌨️ 키보드1~9 0(10) 분모 · B 막대 · C 원 · T 막대 타일 · W 원 조각 · G 다각형 · N 수직선 · E 알 묶음 · A 넓이 모델 · S 분수 쓰기
⑦ 분수 쓰기분수 쓰기를 누르면 입력 칸과 숫자판이 나와요. 키보드나 숫자판으로 2/5 + 1/5 = ? 처럼 바로 쓰면 분수 모양으로 바뀌어요. 대분수는 1 2/3(띄어 쓰기). 고쳐 쓰려면 쓴 분수를 한 번 더 눌러요.
