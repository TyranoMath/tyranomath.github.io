# 🌐 온라인 실시간 대결 설정 방법 (Firebase)

티라노 달리기 연산 대회의 **📺 대회 열기 / 📱 대회 참가**는 여러 기기를 실시간으로 이어 주는 서버가 있어야 동작해요.
구글의 **Firebase 실시간 데이터베이스(Realtime Database)** 를 무료로 쓰면 돼요. 처음 한 번만 설정하면 끝이에요. (약 10분)

> 랭킹(구글 시트 Apps Script)과는 **따로** 설정하는 거예요. 랭킹 설정은 그대로 두세요.

---

## 1. Firebase 프로젝트 만들기

1. <https://console.firebase.google.com> 에 선생님 구글 계정으로 들어가요.
2. **프로젝트 추가(프로젝트 만들기)** 를 눌러요.
3. 프로젝트 이름: `tyranomath` (아무 이름이나 괜찮아요) → 계속
4. Google 애널리틱스는 **사용 안 함**으로 꺼도 돼요 → **프로젝트 만들기**

## 2. 실시간 데이터베이스 만들기

1. 왼쪽 메뉴 **빌드(Build) → Realtime Database** 를 눌러요.
   (Firestore 가 아니라 **Realtime Database** 예요!)
2. **데이터베이스 만들기** 를 눌러요.
3. 위치: **싱가포르 (asia-southeast1)** 를 고르면 우리나라에서 가장 빨라요.
4. 보안 규칙: **잠금 모드로 시작** → **사용 설정**

## 3. 규칙 넣기 (중요!)

1. Realtime Database 화면 위쪽의 **규칙(Rules)** 탭을 눌러요.
2. 안에 있는 글을 모두 지우고, 아래를 그대로 붙여 넣은 뒤 **게시(Publish)** 를 눌러요.

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "rooms": {
      "$code": {
        ".read": true,
        ".write": true,
        ".validate": "$code.matches(/^[0-9]{4}$/)",
        "players": {
          "$id": {
            "n": { ".validate": "newData.isString() && newData.val().length <= 8" }
          }
        }
      }
    }
  }
}
```

- 학생들은 **방 코드(숫자 4자리)를 아는 방만** 읽고 쓸 수 있어요. 전체 방 목록은 아무도 볼 수 없어요.
- 학생 이름은 8글자까지만 들어가요. 로그인·이메일 같은 개인정보는 받지 않아요. **실명 대신 별명**을 쓰게 하면 더 좋아요.

## 4. 주소를 data.js 에 넣기

1. **데이터(Data)** 탭 맨 위에 있는 주소를 복사해요. 이런 모양이에요.
   `https://tyranomath-xxxxx-default-rtdb.asia-southeast1.firebasedatabase.app`
2. TyranoMath 의 **data.js** 를 열고 `liveUrl` 에 붙여 넣어요.

```js
  liveUrl: 'https://tyranomath-xxxxx-default-rtdb.asia-southeast1.firebasedatabase.app'
```

3. GitHub 에 data.js 를 올려요. (1~2분 뒤 사이트에 반영돼요)

## 5. 확인하기

1. 전자칠판에서 **티라노 게임존 → 티라노 달리기 연산 대회 → ⚙️ 설정 → 📺 대회 열기** → 방 코드가 크게 나오면 성공!
2. 학생 기기(또는 선생님 휴대폰)에서 **📱 대회 참가** → 방 코드와 이름을 넣어요.
   - 선생님 화면의 **QR 코드**를 태블릿 카메라로 찍어도 바로 참가 화면이 열려요.
3. 선생님 화면에 학생 이름이 뜨면 **모두 출발! 🏁**

---

## 수업에서 쓰는 순서

| 단계 | 선생님 (전자칠판) | 학생 (태블릿·휴대폰) |
|---|---|---|
| 1 | ⚙️ 설정 → **📺 대회 열기** → (필요하면 ⚙️ 문제 설정) | 게임존 → 티라노 달리기 연산 대회 → **📱 대회 참가** |
| 2 | 방 코드·QR 코드를 보여 줘요 | 방 코드 + 이름 → 들어가기 |
| 3 | 이름이 다 뜨면 **모두 출발! 🏁** | 3·2·1 뒤 같은 문제를 같은 순서로 풀어요 |
| 4 | 전광판에서 반 전체 달리기·순위를 실시간으로 봐요 | 내 트랙에 친구 티라노 3마리가 함께 달려요 · 실시간 순위 |
| 5 | 모두 도착하면 자동으로 끝나요 (🏁 경기 끝내기로 일찍 끝낼 수도 있어요) | 내 등수·기록, 반 순위표 |
| 6 | **같은 방에서 다시 달리기** 또는 **대기실로** · 다 끝나면 **방 닫기** | 다시 시작하면 자동으로 달려요 |

- 기록은 **각자 기기에서 잰 결승선까지 걸린 시간**이라, 인터넷이 조금 느린 학생도 공평해요.
- 경기 중에 들어온 학생도 바로 달릴 수 있어요. (기록은 자기 출발부터 재요)
- 학생이 창을 닫으면 선생님 전광판에서 자동으로 빠져요.

## 알아 두면 좋아요

- **무료 요금제(Spark)** 로 충분해요. 무료 한도는 동시 접속 100명 정도예요. 한 반(30명 안팎)은 넉넉해요.
  (요금제 내용은 바뀔 수 있으니 Firebase 콘솔의 **사용량** 탭에서 가끔 확인해 주세요.)
- **학교 인터넷**에서 `firebasedatabase.app` 주소가 막혀 있으면 연결이 안 돼요. 처음 쓰기 전에 교실에서 한 번 시험해 보세요.
- 선생님이 **방 닫기**를 누르거나 창을 닫으면 방이 지워져요. 혹시 남은 방이 있어도 6시간 뒤에는 새 방이 그 코드를 다시 써요.
  Firebase 콘솔 **데이터** 탭에서 `rooms` 를 직접 지워도 괜찮아요.
- 연결 시험용: 온라인 대회 버튼이 흐리게 보이고 "실시간 서버를 연결하면…" 이라고 나오면 data.js 의 `liveUrl` 이 비어 있거나 잘못된 거예요.
