# 🏆 TyranoMath 실시간 랭킹 켜는 방법

랭킹 기록은 선생님의 **구글 시트**에 모여요. 플레이 수 집계에 쓰는 Apps Script 주소(`statsUrl`) 하나로 랭킹도 함께 돌아가요.

## 1. 처음 설정할 때
1. 새 구글 시트를 만들어요.
2. **확장 프로그램 → Apps Script**를 열어요. `tyrano-stats.gs` 내용을 통째로 붙여 넣고 저장해요.
3. 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 눌러요. 권한 승인 창이 뜨면 허용해요.
   - '플레이수', '랭킹_전체', '랭킹_일별', '금칙어' 탭이 만들어져요.
4. **배포 → 새 배포 → 유형: 웹 앱**을 골라 아래처럼 설정한 뒤 **배포**를 눌러요.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 나온 주소(`https://script.google.com/macros/s/…/exec`)를 `data.js`의 `statsUrl: ''` 따옴표 안에 넣어요.
6. GitHub에 다시 올리면 모든 게임에 **🏆 랭킹** 버튼이 생겨요.
   - 주소가 비어 있으면 랭킹 버튼은 보이지 않아요.

## 2. 이미 플레이 수 집계를 쓰고 있었다면
1. Apps Script 코드를 새 `tyrano-stats.gs`로 바꿔 붙여 넣고 저장해요.
2. `setup`을 한 번 실행해요.
3. **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 눌러요.
   - 주소는 바뀌지 않으니 `data.js`는 그대로 두면 돼요.

## 3. 반 수업에서 쓰기
- 반 코드는 선생님이 정해서 칠판에 알려 주세요. 예) `햇살3-2`
  - 학교 이름이나 별명을 섞으면 다른 학교와 겹치지 않아요.
- 학생이 기록을 올리거나 🏆 랭킹 창의 **바꾸기**에서 반 코드를 넣으면 **🏫 우리 반** 탭에서 우리 반끼리 순위를 볼 수 있어요.
- **🌏 모두** 탭은 사이트 전체 순위예요. 오늘 / 이번 주(월~일) / 전체 기간으로 나눠 볼 수 있어요.
- 랭킹 창은 열려 있는 동안 15초마다 저절로 새로 고쳐져요.

## 4. 기록 관리
- **이상한 기록 지우기**: '랭킹_전체'와 '랭킹_일별' 탭에서 그 줄을 지우면 랭킹에서 사라져요.
  - 15초쯤 지나면 화면에도 반영돼요.
- **닉네임 막기**: '금칙어' 탭 A열에 그 닉네임이나 낱말을 적어요.
  - 그 말이 들어간 닉네임은 랭킹에서 숨겨지고, 다시 올릴 수도 없어요.
- '랭킹_일별' 기록은 15일이 지나면 저절로 정리돼요. 오늘·이번 주 랭킹에만 쓰는 기록이에요.

## 5. 장난 기록을 막는 방법
- 게임을 **시작할 때** 시트에서 '기록표'를 받아요. 이 표가 있어야 기록을 올릴 수 있고, 표는 한 번만 쓸 수 있어요.
- 단계마다 정한 가장 빠른 시간보다 빠른 기록은 받지 않아요.
- 표를 받은 뒤 실제로 그만큼 시간이 지나야 그 기록을 올릴 수 있어요.
  - 예) 40초 기록은 시작하고 40초가 지난 뒤에만 올라가요.
- 점수 게임은 1초에 얻을 수 있는 점수보다 빨리 오른 점수와, 가장 높은 점수를 넘는 점수를 받지 않아요.
- 같은 기기에서 5초 안에 다시 올릴 수 없어요.
- 닉네임은 금칙어를 걸러 내고 한글(완성된 글자)·영어·숫자 2~8글자만 받아요.
  - 'ㅅㅂ'처럼 자음만 쓴 닉네임도 막혀요.

## 6. 게임별 순위 기준
| 게임 | 순위 기준 | 따로 매기는 단위 |
|---|---|---|
| 스도쿠 · 사무라이 스도쿠 · 지뢰 찾기 · 크로스 매스 | 빨리 푼 시간 (힌트를 써도 포함) | 크기·난이도 |
| 그림 로직 | 빨리 푼 시간 | 그림마다 |
| 슬라이딩 퍼즐 | 빨리 맞춘 시간 | 3×3 · 4×4 · 5×5 |
| 오목 | 컴퓨터 티라노를 **적은 수**로 이기기 | 컴퓨터 단계 |
| 블록 쌓기 · 타일 매칭 | 최고 점수 | 시작 단계·층 |
| 게임존 문제 맞히기 게임 | 최고 점수 (같으면 빨리 끝낸 사람) | 단계 |
| 풍선 활쏘기 (1인용) | 최고 점수 | 고른 설정마다 |
| 줄다리기 (1인용) | 컴퓨터 티라노를 빨리 이긴 시간 | 고른 설정마다 |

- 같은 닉네임 + 같은 반 코드는 한 사람으로 보고, 가장 좋은 기록 하나만 보여 줘요.
- 픽셀 아트는 그림을 그리는 놀이라서 랭킹이 없어요. 2인용 대결도 랭킹에 넣지 않아요.
- 게임 엔진(`games/engine/tyrano-quiz.js`)으로 새로 만든 게임은 따로 설정하지 않아도 랭킹이 생겨요.

## 7. 🐞 버그 제보 게시판
- 같은 구글 시트 주소(`statsUrl`)로 **버그 제보방 게시판**(`bugboard.html`)도 함께 열려요. 따로 설정할 것은 없어요.
  - 이미 배포했다면 새 `tyrano-stats.gs`를 붙여 넣고 **새 버전으로 배포**만 해 주세요.
- 학생이 올린 글은 시트의 **'버그제보'** 탭에 쌓여요. 기기 정보는 자동으로 함께 저장돼요.
- 선생님이 시트에서 할 일:
  - **상태** 칸: `접수` → `확인 중` → `해결` (`해결 안 함`, `보류`도 쓸 수 있어요)
  - **선생님 답변** 칸: 적으면 게시판 글 아래에 "🦖 선생님 답변"으로 보여요.
  - **숨김** 칸: 아무 글자(예: O)나 적으면 게시판에서 숨겨져요.
- 게임·도구 창 위쪽의 **🐞 제보** 버튼을 누르면 어떤 게임이었는지 자동으로 채워진 채 게시판이 열려요.
- 장난 글 막기:
  - 욕설이 들어간 글은 올라가지 않아요.
  - 같은 기기에서는 1분에 1개, 하루 10개까지만 올릴 수 있어요.
  - 학생은 선생님 답변이 달리기 전까지만 자기 글을 지울 수 있어요.
- `statsUrl`이 비어 있고 `bugReportUrl`(구글 설문지 주소)만 넣었다면 🐞 버튼은 설문지로 연결돼요.
